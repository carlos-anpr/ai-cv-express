## 🎯 Resumen Rápido

### ¿Qué es Generación Express?

Una funcionalidad revolucionaria que permite a los usuarios crear un **CV completo + Carta de Presentación + Candidatura** en menos de 5 minutos, simplemente pegando la información de una oferta de trabajo y describiendo brevemente su perfil profesional.

### Flujo Simplificado

```
1. Usuario accede → Botón "Generación Express" en Dashboard
2. Paso 1 → Describe su perfil (estudios, experiencia, sector)
3. Paso 2 → Pega información de la oferta de trabajo
4. Paso 3 → IA procesa y genera todo automáticamente
5. Resultado → CV personalizado + Carta + Candidatura guardada
```

### Tecnologías Clave

- **Frontend:** React + shadcn/ui
- **IA:** Google Gemini 2.0 Flash
- **Base de Datos:** IndexedDB (local)
- **Estado:** React Context
- **Validación:** Zod
- **Animaciones:** Framer Motion
