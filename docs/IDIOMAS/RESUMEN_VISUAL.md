## 📊 Datos Técnicos

### **Estructura de Datos:**

```javascript
{
  languages: [
    {
      name: 'Inglés', // String - Requerido
      level: 'C1', // String (A1-C2) - Requerido
      certification: 'TOEFL 110', // String - Opcional
    },
    {
      name: 'Francés',
      level: 'B2',
      certification: 'DELF B2',
    },
  ];
}
```

### **Validación:**

- ✅ Al menos 1 idioma con nombre y nivel
- ✅ Certificación opcional (puede estar vacía)
- ✅ Niveles restringidos a A1, A2, B1, B2, C1, C2
