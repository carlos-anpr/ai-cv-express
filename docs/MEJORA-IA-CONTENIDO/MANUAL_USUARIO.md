# Manual de Usuario: Mejora de Contenido con IA

## 📖 Introducción

Esta guía te ayudará a aprovechar al máximo las nuevas funcionalidades de generación y mejora de contenido con IA en el AI Resume Builder.

---

## 🎯 ¿Qué hay de nuevo?

### 1. Mejora Inteligente de Resumen

Ya no solo puedes generar resúmenes desde cero. Ahora la IA puede **mejorar tu texto actual**, mantener tu estilo personal y ampliar tu contenido de forma profesional.

### 2. Mejora de Experiencia Laboral

La IA ahora puede **mejorar tus descripciones existentes**, reorganizarlas profesionalmente y ampliarlas con más detalles y contexto.

### 3. Generación Automática de Habilidades

Describe tus habilidades en **lenguaje natural** (como si hablaras con un amigo) y la IA las convertirá automáticamente en una lista estructurada con niveles de dominio.

---

## 📝 Guía de Uso: Resumen Profesional

### Caso 1: Generar desde Cero

**Cuando usar**: No tienes nada escrito o quieres empezar de nuevo.

**Pasos**:

1. Ve a la sección "Resumen Profesional"
2. Deja el campo de texto vacío
3. Haz clic en **"Generar con IA"**
4. La IA generará 3 opciones para diferentes niveles:
   - Junior/Principiante
   - Nivel Medio
   - Senior
5. Haz clic en la opción que prefieras
6. Se copiará automáticamente al campo de texto

**Ejemplo**:

```
Puesto: "Desarrollador Full Stack"

Opciones generadas:
→ Junior: 4-5 líneas enfocadas en aprendizaje
→ Medio: 5-6 líneas con proyectos específicos
→ Senior: 6-7 líneas con liderazgo y arquitectura
```

### Caso 2: Mejorar Texto Existente

**Cuando usar**: Ya tienes algo escrito pero quieres hacerlo más profesional.

**Tu texto actual**:

```
Soy desarrollador con experiencia en JavaScript.
He trabajado en varios proyectos web.
```

**Pasos**:

1. Escribe o pega tu resumen actual
2. Haz clic en **"Mejorar con IA"** (el botón cambia automáticamente)
3. Selecciona una opción:

   - **Mejorar mi texto actual**: Mantiene tu contenido, lo hace más profesional
   - **Ampliar y hacer más atractivo**: Añade detalles y contexto
   - **Generar nuevas opciones**: Crea versiones completamente nuevas

4. Revisa el resultado en el panel de vista previa
5. Opciones disponibles:
   - ✅ **Aplicar**: Reemplaza tu texto con la versión mejorada
   - 🔄 **Regenerar**: Genera otra versión
   - ❌ **Cancelar**: Mantiene tu texto original

**Resultado mejorado**:

```
Desarrollador Full Stack con sólida experiencia en JavaScript
y tecnologías modernas. He participado en el desarrollo de
múltiples aplicaciones web, implementando soluciones escalables
y optimizadas que han mejorado la experiencia del usuario y
aumentado la eficiencia operativa.
```

### Caso 3: Ampliar Contenido

**Tu texto actual**:

```
Desarrollador con 3 años de experiencia en React.
```

**Selecciona**: "Ampliar y hacer más atractivo"

**Resultado ampliado**:

```
Desarrollador Full Stack con 3 años de experiencia especializado
en React y su ecosistema. He liderado la implementación de
aplicaciones web modernas utilizando React, Redux y React Hooks,
aplicando principios de diseño atómico y arquitectura de componentes
reutilizables. Mi enfoque se centra en crear interfaces de usuario
intuitivas y de alto rendimiento, optimizando la experiencia del
usuario y asegurando la escalabilidad del código mediante mejores
prácticas y testing automatizado.
```

## 💼 Guía de Uso: Experiencia Profesional

### Caso 1: Generar desde Cero

**Cuando usar**: Acabas de añadir un nuevo trabajo y no sabes qué poner.

**Requisito**: Debes tener el título del puesto lleno.

**Pasos**:

1. Añade un nuevo trabajo con **"+ Añadir Más Experiencia"**
2. Rellena al menos:
   - Título del puesto
   - Nombre de la empresa
3. En el campo "Resumen", haz clic en **"Generar con IA"**
4. La IA generará 5-7 puntos clave relevantes para ese puesto
5. Los puntos se insertarán automáticamente como lista con formato

**Ejemplo**:

```
Puesto: "Desarrollador Frontend React"

Puntos generados:
• Desarrollé componentes reutilizables utilizando React y TypeScript
• Implementé arquitectura basada en componentes siguiendo atomic design
• Optimicé el rendimiento de aplicaciones reduciendo tiempos de carga
• Colaboré con diseñadores UX/UI para implementar interfaces intuitivas
• Realicé code reviews y mentoría a desarrolladores junior
• Implementé testing automatizado con Jest y React Testing Library
```

### Caso 2: Mejorar Puntos Existentes

**Cuando usar**: Tienes una descripción básica y quieres mejorarla.

**Tu descripción actual**:

```
• Desarrollé aplicaciones web
• Trabajé con React y Node
• Ayudé al equipo
```

**Pasos**:

1. Haz clic en **"Mejorar con IA"**
2. Selecciona una opción:

   - **Mejorar puntos actuales**: Hace profesional mantener la estructura
   - **Ampliar con más detalles**: Añade contexto y métricas
   - **Reorganizar profesionalmente**: Ordena por impacto

3. Revisa el resultado
4. Aplica o regenera según prefieras

**Resultado mejorado (Opción: Mejorar puntos)**:

```
• Desarrollé aplicaciones web full-stack utilizando arquitectura
  moderna y siguiendo mejores prácticas de desarrollo
• Implementé soluciones técnicas con React en el frontend y Node.js
  en el backend, optimizando el rendimiento y la escalabilidad
• Colaboré activamente con el equipo mediante metodologías ágiles,
  contribuyendo al éxito de proyectos críticos
```

**Resultado ampliado (Opción: Ampliar con más detalles)**:

```
• Lideré el desarrollo de aplicaciones web full-stack desde la
  concepción hasta el despliegue, utilizando arquitectura basada
  en microservicios y aplicando principios SOLID. Implementé CI/CD
  para automatizar procesos [ej: reduciendo tiempo de deploy en 40%]

• Diseñé e implementé soluciones técnicas robustas con React 16+
  (incluyendo Hooks y Context API) en el frontend y Node.js con
  Express en el backend. Optimicé queries de base de datos y
  implementé caching estratégico [ej: mejorando tiempos de respuesta
  en 60%]

• Facilité la colaboración efectiva del equipo mediante metodologías
  ágiles (Scrum), participando en daily standups, sprint planning y
  retrospectivas. Mentoricé a 3 desarrolladores junior en mejores
  prácticas de código y contribuí a la documentación técnica del proyecto
```

### Caso 3: Reorganizar Profesionalmente

**Cuando usar**: Tienes buenos puntos pero no están ordenados por impacto.

**Selecciona**: "Reorganizar profesionalmente"

La IA reordenará tus puntos poniendo primero los más impactantes y relevantes para el puesto.

## 🎯 Guía de Uso: Habilidades

### Nueva Interfaz con Pestañas

La sección de habilidades ahora tiene dos modos:

```
┌─────────────────────────────────────┐
│  [✏️ Manual]  [🤖 Generar con IA]  │
└─────────────────────────────────────┘
```

### Modo 1: Manual (Tradicional)

**Cuando usar**: Sabes exactamente qué skills añadir y su nivel.

**Pasos**:

1. Selecciona la pestaña **"✏️ Manual"**
2. Haz clic en **"+ Añadir Más Habilidad"**
3. Escribe el nombre de la habilidad
4. Ajusta el nivel con las estrellas (1-5)
5. Repite para cada habilidad

**Ventajas**:

- Control total sobre nombres
- Ajuste fino de niveles
- Rápido si tienes pocas habilidades

### Modo 2: Generar con IA (Nuevo)

**Cuando usar**: Tienes muchas habilidades o no estás seguro de cómo clasificarlas.

**Pasos**:

1. Selecciona la pestaña **"🤖 Generar con IA"**

2. Describe tus habilidades en lenguaje natural como si hablaras con un amigo:

**Ejemplo de descripción**:

```
Domino Node.js a nivel experto, he trabajado con él por 5 años.
React lo manejo con conocimientos básicos, solo he hecho un par
de proyectos. TypeScript nivel intermedio. También sé Docker y
Kubernetes para deploy de aplicaciones.
```

3. Haz clic en **"Generar Habilidades con IA"**

4. La IA analizará tu texto y generará:

```
┌─────────────────────────────────┐
│ ✨ Habilidades Generadas        │
├─────────────────────────────────┤
│ Node.js       ⭐⭐⭐⭐⭐        │
│ React         ⭐⭐☆☆☆          │
│ TypeScript    ⭐⭐⭐☆☆          │
│ Docker        ⭐⭐⭐⭐☆          │
│ Kubernetes    ⭐⭐⭐⭐☆          │
└─────────────────────────────────┘
```

5. Revisa las habilidades generadas:
   - ✏️ **Editar**: Cambia nombre o nivel
   - 🗑️ **Eliminar**: Quita habilidades que no quieres
   - ✅ **Aplicar Todas**: Añade al listado principal

### Cómo la IA Detecta Niveles

La IA busca palabras clave en tu descripción:

| Palabras Clave                               | Nivel Asignado | Estrellas  |
| -------------------------------------------- | -------------- | ---------- |
| Experto, Avanzado, Dominio, 5+ años          | Experto        | ⭐⭐⭐⭐⭐ |
| Intermedio, Medio, Sólido, 2-4 años          | Intermedio     | ⭐⭐⭐☆☆   |
| Básico, Principiante, Conocimientos, <2 años | Básico         | ⭐⭐☆☆☆    |

**Si no mencionas nivel**, asume **Intermedio** (3 estrellas).

### Editar Skills Generadas

Antes de aplicar, puedes editar cada skill:

1. Haz clic en el botón ✏️ **Editar** de la skill
2. Cambia el nombre si lo deseas
3. Ajusta el nivel con las estrellas
4. Haz clic en ✅ para guardar o ❌ para cancelar

### Combinar Modo Manual y IA

Puedes usar ambos modos:

1. Genera algunas skills con IA
2. Cambia a modo Manual
3. Añade más skills manualmente
4. Guarda todo junto

**Las skills no se duplican**: Si generas una skill que ya existe, la IA la detectará.

## 💡 Consejos y Mejores Prácticas

### Para Resumen Profesional

✅ **Haz**:

- Empieza con algo básico y déjalo mejorar por la IA
- Usa "Mejorar" antes que "Ampliar" si tu texto es corto
- Prueba múltiples versiones con "Regenerar"
- Combina lo mejor de tu texto con las sugerencias de IA

❌ **Evita**:

- Dejar el campo completamente vacío y esperar un resumen perfecto
- Aceptar la primera sugerencia sin leer
- No mencionar tu especialización o área

### Para Experiencia Profesional

✅ **Haz**:

- Escribe primero logros y números reales que tengas
- Usa "Ampliar" para añadir contexto a tus logros
- Usa "Mejorar" si tus puntos son muy informales
- Menciona tecnologías específicas que usaste

❌ **Evita**:

- Generar experiencia completamente inventada
- Aceptar métricas sugeridas sin verificar [ej: 40%]
- No personalizar después de generar

### Para Habilidades

✅ **Haz**:

- Sé honesto con tu nivel de dominio
- Menciona años de experiencia si los tienes
- Describe proyectos donde usaste la tecnología
- Revisa y ajusta los niveles generados

❌ **Evita**:

- Exagerar tu nivel de dominio
- Listar skills que no conoces realmente
- No revisar las skills generadas antes de aplicar

## 🔧 Solución de Problemas

### "Por favor añade primero el título del puesto"

**Problema**: Intentas generar contenido sin título de puesto.

**Solución**:

1. Ve a "Detalles Personales"
2. Rellena el campo "Título del Puesto"
3. Guarda
4. Vuelve a intentar

### El botón "Generar con IA" no hace nada

**Problema**: No hay respuesta al hacer clic.

**Solución**:

1. Verifica tu conexión a internet
2. Recarga la página
3. Verifica que has configurado la API key de Gemini
4. Revisa la consola del navegador (F12) para errores

### La IA genera contenido en inglés

**Problema**: El contenido generado no está en español.

**Solución**: Esto no debería pasar ya que los prompts especifican español. Si ocurre:

1. Regenera el contenido
2. Si persiste, reporta el bug

### Las skills generadas no son correctas

**Problema**: La IA no detectó bien tus habilidades.

**Solución**:

1. Sé más específico en tu descripción
2. Usa palabras clave claras: "experto", "básico", "intermedio"
3. Separa claramente cada habilidad
4. Edita manualmente las skills incorrectas antes de aplicar

### El preview no se cierra

**Problema**: El diálogo de preview está atascado.

**Solución**:

1. Haz clic en "Cancelar"
2. Si no funciona, presiona ESC
3. Como último recurso, recarga la página

## ❓ Preguntas Frecuentes

### ¿Puedo usar la IA sin internet?

No, se requiere conexión a internet para comunicarse con Gemini AI.

### ¿La IA guardará mi información?

No, todo se procesa en tiempo real y se guarda localmente en tu navegador.

### ¿Cuántas veces puedo generar contenido?

Ilimitadas, pero ten en cuenta posibles límites de la API de Gemini.

### ¿Puedo editar el contenido después de aplicar?

Sí, siempre puedes editar manualmente después de aplicar sugerencias de IA.

### ¿La IA reemplaza mi contenido sin preguntar?

No, siempre muestra un preview y pide confirmación antes de aplicar cambios.

### ¿Qué pasa si no me gusta la sugerencia?

Puedes:

1. Regenerar para obtener otra versión
2. Cancelar y mantener tu texto original
3. Editar manualmente la sugerencia

### ¿Los reclutadores sabrán que usé IA?

No, el contenido generado se personaliza según tu información y se integra naturalmente.
